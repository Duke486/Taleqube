# 产品与交互

## 产品定位

AniShelf 是用户自己的影视与书籍仓库：用统一主作品承载个人评分和进度，再把其他平台作为发现、来源记录、评分展示和同步渠道。用户不会为了每一集重新打开应用，进度以作品或季为单位编辑。设备直接访问平台 API，账号和 AI 密钥由用户配置；操作文案面向使用者。

## 组织方式

首页聚合最近观看、最新入库、继续观看或阅读、推荐与随机作品；发现页按电影、剧集、动漫和书籍搜索各平台；资料库管理本机作品。AniList 和 Trakt 片单是独立入口，呈现平台自己的记录，不改变本机分类。iPad 使用系统侧边栏／顶部 Tab，iPhone 使用底部主导航。

电影和剧集以 TMDB 为主条目，漫画及书籍以 AniList 为主条目。浏览、搜索和建立平台关联不会自动入库；用户明确入库或保存评分、状态时才建立本机记录。平台导入逐项确认，不向远端回写；重复导入保留本机评分和状态。主平台没有对应作品时，导入界面允许明确选择直接添加来源条目作为例外。

## 详情与浏览

作品详情汇集简介、平台评分、个人评分和进度、季集资料、剧照与平台关联。整部评分位于简介之前，剧照紧随简介；季评分与状态在季卡片内编辑。详情用系统缩放 sheet，iPad 目标宽度 700pt。海报与背景横图仅展示；剧照浏览器支持全屏图片缩放。

季、剧集和剧照选择保持当前滚动位置；浏览器内部翻页后关闭仍返回最初点击的卡片。网格支持双指缩放列数并记住密度。海报长按只上浮海报，状态菜单沿用角标颜色。

观看编辑保留作品和季级进度，不提供逐集观看操作。TMDB 剧集主状态汇总明确标记的正片季，优先级为重温、在看、计划、暂停或放弃、完成；暂停与放弃同级时采用最近一次明确标记，特别篇及未标记季不参与。Infuse 入口面向所有有有效 TMDB 匹配的影视作品，不受是否入库或打开来源限制，只打开对应详情页，不写入观看状态。关闭详情时，未保存修改或进行中的 AI 匹配需要用户确认。

## 关联和同步

关联可以表达同一平台的多个条目，支持拆季、跨季与复杂集对应。手动匹配点击条目直接确认；支持多选的关联类型通过独立复选框累积后批量提交。关联调整即时保存，与详情中尚未保存的评分、进度草稿分开。

本机保存后可按配置同步评分、状态和进度到平台。同步失败不撤销本机保存；记录保留步骤与错误，重试使用最新关系与个人记录。

相关实现：`Features/TrackingView.swift`、`LibraryViews.swift`、`WorkSheet.swift`、`MediaGalleryView.swift`、`MatchPickerView.swift`、`Poster.swift`。

## 平台与设置

| 平台 | 作用 | 连接方式 |
| --- | --- | --- |
| TMDB | 影视主身份、季集、剧照与平台评分；账号可写入整部评分 | 读取令牌；评分另需登录账号 |
| AniList | 书籍主身份、动漫与书籍发现、个人片单 | Client ID 授权或访问令牌 |
| Trakt | 影视发现、最近观看、个人片单与同步 | Client ID 和设备码登录 |
| MyAnimeList | 动漫、书籍发现和关联同步 | Client ID 授权或令牌 |
| Bangumi | 动漫、影视及书籍发现和关联同步 | 个人访问令牌 |
| DeepSeek／OpenAI | 翻译和匹配 | 各自 API Key；联网查找中文名与搜索补证使用 DeepSeek |

设置将账号、翻译与匹配、数据分开。手动输入的配置需保存；登录、断开及数据操作即时执行。可导出完整备份或迁移账号二维码；完整备份包含明文凭据。
