# 源码索引

项目不是按一个类型一个文件拆分；`Tracking.swift` 和 `WorkSheet.swift` 分别集中承载多平台数据与详情协调。查功能时先从当前入口往下追踪。

## 应用与领域

| 文件 | 从这里查什么 |
| --- | --- |
| `App/TalequbeApp.swift` | 应用入口、环境对象、键盘命令 |
| `App/AppStore.swift` | AniList 授权、浏览和旧界面状态 |
| `Core/Models.swift` | AniList 媒体、片单与书籍详情模型 |
| `Core/AniListAPI.swift` | AniList GraphQL 查询、片单和个人记录 |
| `Core/Tracking.swift` | `Work`、`TrackingRecord`、平台适配、备份、草稿、同步队列 |
| `Core/LibraryIdentity.swift` | 主身份、来源记录、季级状态、旧关联迁移和评分继承 |
| `Core/ContentMapping.swift` | 映射数据、验证、平台进度投影、匹配结果合并 |
| `Core/MatchingMetadata.swift` | 匹配所需 TMDB 季集表与平台详情 |
| `Core/SeasonMatching.swift` | 六轮季集 Agent、模型升级、补证、结果和状态 |
| `Core/Intelligence.swift` | 模型请求、结构化解析、翻译、中文名和身份判断 |
| `Core/MediaLanguage.swift` | 搜索、别名、文本清理、共享请求及身份匹配协调 |
| `Core/Artwork.swift` | 图片与季集元数据、图片主题色、演员和主创 |
| `Core/Authentication.swift`、`Core/PlatformLogin.swift` | AniList 授权、其他平台登录与钥匙串 |
| `Core/Diagnostics.swift` | 日志脱敏、持久化和增量导出 |

## 视图与资源

| 文件 | 从这里查什么 |
| --- | --- |
| `Features/TrackingView.swift` | 当前主导航、首页、资料库、详情和工具弹窗入口 |
| `Features/LibraryViews.swift` | 发现、平台片单、网格缩放及逐项导入 |
| `Features/WorkSheet.swift` | 当前作品详情、草稿、季、关联、匹配与同步记录 |
| `Features/MatchPickerView.swift`、`Features/MappingEditorView.swift` | 手动选条目、内容对应编辑与校验 |
| `Features/MediaGalleryView.swift` | 详情头图、剧照／剧集浏览器和全屏图片 |
| `Features/Poster.swift` | 图片缓存、封面、观看状态及书籍角标 |
| `Features/BookDetailSections.swift` | 书籍人物、关联作品及影视演员主创 |
| `Features/ConnectionsView.swift` | 当前设置、账号、备份、诊断和二维码迁移 |
| `Features/WorkspaceView.swift`、`Features/BrowserView.swift`、`Features/MediaDetailView.swift`、`Features/SettingsView.swift` | 另一组以 `AppStore` 为状态的 AniList 工作区及其子界面；当前 `TalequbeApp` 直接打开 `TrackingView` |
| `Resources/Info.plist` | 应用 URL scheme 和权限说明 |
| `Resources/Assets.xcassets`、`AppIcon.icon` | 平台图标、色彩和分层应用图标 |
| `Design/` | 图标和取色预览、平台图标来源 |

测试与脚本的对应关系见 [开发与验证](开发与验证.md)。
