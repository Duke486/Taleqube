# 开发与验证

## 构建

使用 Xcode 27+ 打开 `AniShelf.xcodeproj`，设置签名团队和 Bundle Identifier。命令行构建模拟器目标：

```sh
./Scripts/build-simulator.sh
```

脚本使用 iOS Simulator SDK 构建，关闭代码签名。账号、平台令牌与 AI 密钥在应用设置中配置；相关服务和回调地址见根目录 [README.md](../README.md)。

## 回归检查

| 命令 | 关注范围 |
| --- | --- |
| `./Scripts/check-concurrency.sh` | DeepSeek 30 并发、取消、平台并发与串行提交、写入顺序、同步追加任务 |
| `./Scripts/check-core.sh` | AniList 模型、OAuth、查询与分页 |
| `./Scripts/check-tracking.sh` | 记录、平台请求与同步 |
| `./Scripts/check-persistence.sh` | 持久化、恢复与备份 |
| `./Scripts/check-language.sh` | 多语言搜索、翻译与图片主题 |
| `./Scripts/check-matching.sh` | 身份匹配 |
| `./Scripts/check-season-matching.sh` | 季集匹配与补证 |
| `./Scripts/check-book-matching.sh` | 书籍类型与匹配 |
| `./Scripts/check-details.sh` | 详情相关规则 |

对应检查代码位于 `Tests/`，导航 UI 测试位于 `Tests/NavigationUITests.swift`，由共享 scheme `AniShelfNavigation` 运行。脚本检查用 `swiftc` 编译核心源码与对应检查文件，并使用本地替身响应。选择与改动有关的检查，并在交互或布局变化时于可运行设备上验收。

## 查找入口

- 主导航与首页：`Features/TrackingView.swift`；发现、资料库与导入：`Features/LibraryViews.swift`。
- 作品详情与编辑：`Features/WorkSheet.swift`；剧集和剧照浏览：`Features/MediaGalleryView.swift`。
- 手动匹配与映射编辑：`Features/MatchPickerView.swift`、`MappingEditorView.swift`。
- 平台账号、备份和诊断界面：`Features/ConnectionsView.swift`、`SettingsView.swift`。
- 领域数据、持久化和同步：`Core/Tracking.swift`、`LibraryIdentity.swift`、`ContentMapping.swift`。
- AI 与季匹配：`Core/Intelligence.swift`、`MediaLanguage.swift`、`SeasonMatching.swift`、`MatchingMetadata.swift`。

## 性能排查线索

主线程上的草稿和资料库持久化、启动迁移、备份导入导出，以及图片所有者索引和详情模糊是性能排查的重要路径。现有 [UI 性能排查报告](../Reports/UI-performance-audit-2026-10-31.txt) 记录了源码检查结果与建议的真机测量场景；它没有设备帧时间数据。

## 并发实现（2026-10-31）

- `RequestPermits` 在实际 DeepSeek 网络请求入口统一限流为 30；模型与联网工具共享，等待使用 continuation，不占线程。
- `ConcurrentPlatformMatching` 并发计算各平台结果，由单个消费者按完成顺序提交；`PlatformMatchingOutcome` 将平台增量应用于最新记录。详情页检查本地与资料库关联快照，避免覆盖中途的人工修改。
- `AIRequestDeadline.map` 使用滚动任务池；普通元数据请求默认并发 3。首页跨平台推荐与片单刷新独立完成。
- `persistAsync` 将高频完整备份编码、冲突检测、恢复副本与原子写入放到串行后台队列；同步步骤回调排队写入。保留同步 API 用于启动迁移、备份导入导出及现有同步交互边界，因此这些低频路径仍可能等待磁盘。
- 草稿写入按调用顺序执行，内存可立即读取；测试模拟重启前调用 `flushDrafts()` 等待持久化。关闭／切后台场景应验收最新草稿恢复。
- 图片解码独立限流为 4，按尺寸档位缓存缩略图；全屏浏览读取完整分辨率，命中缓存时的文件时间更新限频。

本轮验证：并发 20 项、持久化 96 项、语言与图片 189 项、同步 238 项、季匹配 124 项、书籍匹配 53 项、身份匹配 45 项、详情 17 项，共 782 项通过；图片缓存磁盘策略回归与 iOS Simulator 构建通过。
