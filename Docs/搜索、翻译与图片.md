# 搜索、翻译与图片

## 搜索与中文名

`MediaSearch` 是发现、平台搜索、关联与导入共用的搜索层。它先用输入标题／原名查目标平台，合并并按作品 ID 去重，再按需查询别名并补充搜索；网络失败记录为提示，不当作空结果。影视寻找 TMDB 时先复用已确认关联或有效外部 ID，否则搜索并让 AI 从候选中确认。书籍匹配会先过滤已知的类型和系列／单卷冲突，再按需补充详情与证据。

`Intelligence.researchNames` 使用作品标题、原名、类型、年份和简介等信息，最多三轮构造搜索词、调用 DeepSeek 搜索并综合回答；有可靠结果可提前结束，搜索为空也会进入回答。返回结果区分联网查证、模型已知译名和翻译；引用索引与链接需校验。`MediaLanguage` 清理 HTML、识别中文、规范和去重搜索词。标题与简介译文保存原文身份，原文变化后失效；后台结果不得覆盖期间的手动改名。

自动标题翻译按最多 12 项批处理，输出截断时拆批；人物、角色、相关作品等元数据以字段 ID 批量翻译并检查缺项。共享名称和简介请求按订阅者管理，最后一个调用者取消时终止请求。

## 图片和主题

`CatalogAPI.artwork` 读取作品背景和季资料，`episodes` 按季读取剧集；图片地址和季信息由 `ArtworkMetadataCache` 缓存 24 小时，同作品并发请求合并。`PosterCache` 管理图片字节的磁盘缓存和已解码图片的内存缓存；图片本身与元数据分开失效。集卡片只为可见区域和前后各三集加载图片与简介。

`ArtworkPalette` 根据图片色群、色相和亮度提取种子色，`ArtworkTheme` 用 OKLCH 生成背景、卡片、文字及强调色。详情优先从横图取色，再回退到其他背景和海报；系统深色始终保持深色，深色作品也可在系统浅色下使用深色详情。主题色供详情和剧集／剧照浏览器共享，文字对比度由色阶计算约束。

实现入口：`Core/MediaLanguage.swift`、`Intelligence.swift`、`Artwork.swift`；`Features/Poster.swift`、`MediaGalleryView.swift`；详情加载协调位于 `Features/WorkSheet.swift`。
