# AniShelf 文档

AniShelf 是面向 iPhone 和 iPad 的原生 SwiftUI 影视与书籍资料库。影视以 TMDB 为主身份，书籍以 AniList 为主身份；其他平台的条目通过关联映射到主作品。本机资料库、平台片单和远端同步各有边界：浏览或关联不会自动入库，保存本机记录与同步到平台是不同的操作。

- [架构与数据](架构与数据.md)：入口、模块、数据流、存储和同步。
