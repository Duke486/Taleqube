# Taleqube

Tale（故事）与 Cube（立方体）的组合命名。电影、剧集、动漫、漫画和轻小说，汇聚成自己的故事收藏。

品牌主名称统一使用 **Taleqube**，保留首字母大写，不缩写成 TQ，不附加未经确定的中文产品名。

品牌主张：**把热爱，收藏成宇宙。**

标识以立方体的三个面承载书页和播放符号；三面分别表达发现、阅读与观影。小尺寸优先使用图形，横向空间使用图形与 Taleqube 字标。

| 用途 | 色值 |
| --- | --- |
| 主色／图标底色 | `#4939B7` |
| 顶面／辅助色 | `#BDB2FF` |
| 书页面／暖色 | `#F5C798` |
| 屏幕面／浅色 | `#F7F4FF` |

字标使用系统圆角无衬线粗体，正文沿用系统字体。应用中作品详情的动态取色继续由作品图片决定。

源文件：`Taleqube-mark.svg` 为透明标识，`Taleqube-icon.svg` 为完整应用图标预览；应用使用同源分层 SVG 与 Icon Composer 材质。

## 升级兼容

Taleqube 延续 AniShelf 的安装身份、本机资料库目录、Keychain 服务名、OAuth 回调地址、S3 对象前缀和加密格式。这些是兼容标识，不作为对外品牌展示。已有用户无需重新导入收藏或重新配置平台开发者回调。

新备份扩展名为 `.taleqube`，继续接受 `.anishelf`；档案格式和加密头不变。项目工程与共享 scheme 使用 `Taleqube.xcodeproj`、`Taleqube` 和 `TalequbeNavigation`。
