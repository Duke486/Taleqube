# AI 翻译与跨平台关联

## 配置

在设置 → 翻译与匹配中填写自己的 DeepSeek / OpenAI API Key 并保存。DeepSeek Key 还用于联网查询作品中文名与别名；复杂匹配会按配置使用高级模型，因此请确认对应服务可用。

应用的模型与请求实现见仓库 `Taleqube/Core/Intelligence.swift`。当前默认常规模型为 `deepseek-flash`，复杂判断可升级到已配置的 `gpt-6.1-terra`；实际调用需由服务端支持对应模型。模型用量按用户所配置服务的规则计费。

## 翻译

- 在作品详情翻译简介，随时切换原文与译文。
- 查找中文译名时结合多语言标题和联网资料；也可手动改名。
- 译名和译文保存到本机；原文改变时重新处理对应译文。
- AI 请求按功能发送作品标题、简介、候选或季集资料到已配置服务。

## 关联

进入作品详情的「平台关联」，自动匹配所有平台或单独匹配某个平台。关联到的条目会展示范围、评分来源与内容对应状态。

常规关联先用轻量元数据判断，再按缺项读取平台详情、TMDB 季集表或联网补证。清晰结果可提前完成，复杂匹配最多六轮，并可升级到已配置的高级模型裁决。完整一对一正片季默认逐集对应；拆季、跨季自动尝试集对应。特别篇单独核对实际 S00 内容。

## 修正

点击手动匹配结果直接确认；支持多选的关联通过末尾复选框累积，再批量确认。可调整对应范围、编辑内容映射，或使用「AI 补全集对应」重试。人工锁定的关联受到保护。

进度按已确认的内容对应同步；无对应时跳过该条目的进度，评分独立处理。修改关联后旧待同步任务失效，重试使用当前记录。
